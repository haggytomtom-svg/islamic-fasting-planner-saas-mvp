# SaaS Roadmap

## Phase 1 - MVP

- Hosted dashboard
- User signup/login
- User profile
- Personal fasting tracker
- CSV and ICS export
- Basic subscription gating
- Staging deployment with health check
- Environment preflight checks

## Phase 2 - Security And Billing

- Email verification
- Authenticator app MFA
- Email OTP fallback
- Recovery codes
- Stripe checkout
- Subscription portal
- Login alerts

## Phase 3 - Admin Governance

- Moon-sighting confirmation console
- Regional methodology management
- Audit logs
- Admin announcement banner
- Versioned calendar updates

## Phase 4 - Premium Product

- Annual fasting reports
- Family/member profiles
- PDF monthly planner
- Bilingual Arabic/English interface
- Mobile PWA
- Reminder emails
- Google/Outlook calendar sync
